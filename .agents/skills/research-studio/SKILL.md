# Notebook Studio

用户在 Studio 上传 PDF 后，Studio 会逐篇建立索引；等待资料状态为“已索引”再做跨篇回答。调用 `studio_search` 检索当前会话，不要自行猜测附件的存储路径，也不要把全部 PDF 塞进一个模型请求。

回答时对每项主要事实标注工具返回的文献名称、页码及证据 ID；只根据检索到的页面陈述结论。中英文术语不一致时换用英文关键词再次检索。证据不充分或冲突时说明局限，不要编造指标、图号、DOI 或文献观点。报告与 PPT 中的 AI 概念图仅作示意，不能替代论文原图或证明实验结论。用户没有配置图片模型时不要建议虚构插图。

Studio 成稿只使用用户在本次生成中勾选的 PDF；可选择从提示词关键词检索网络背景。网络来源以 `[Wn]`、URL 和检索时间单独记录，不得当作 `[n] PDF p.x` 的论文证据。生成演示文稿时须完成逐页证据成稿，不要把可编辑大纲当作最终幻灯片正文。用户可在 Studio 选择报告 DOCX/PDF 或演示 PPTX/PDF；资料授权、真实成稿质量及排版仍需人工确认。
